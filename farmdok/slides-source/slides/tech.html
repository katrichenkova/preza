Фармдок · 12 · Стек — решение команды

(15:51–16:50) Теперь о технологиях. Серверная часть написана на Python, веб-версия — на TypeScript и React, приложения для телефона — на Flutter, это одна кодовая база для iOS и Android, что важно для команды из трёх разработчиков. Данные хранятся в PostgreSQL, для поиска по договорам используется OpenSearch, файлы — в S3-совместимом хранилище. При этом изоляция не мешает интеграции: Фармдок легко подключается по API к 1С, операторам ЭДО и сервисам проверки контрагентов. На старте нам хватает российского облака примерно за пятьдесят тысяч рублей в месяц, и эти расходы уже заложены в финансовую модель. Все компоненты открытые или российские, поэтому продукт можно включить в реестр отечественного программного обеспечения.
